# CLAUDE.md

各種ドキュメントを確認しながら動作するように

## 各種ドキュメントの役割

### AGENTS.md

- 基本的な思考と動作の指示

### README.md

- エージェントが更新する
- プロジェクトの説明、機能の説明など
- 将来実装予定、更新履歴は記載しない

### UPDATE.md

- エージェントが更新する
- プロジェクトの更新履歴を時系列順に追記していく
- 機能的な更新内容、実装構造的な更新内容、またその理由を記載していく

### PLAN.md

- エージェントが更新する
- 将来やることをリストアップする
- 実装したら記載を削除していく

### MEMORY.md

- エージェントが更新する
- 作業教訓・思考方法の記録
- このファイルはAIがセッションをまたいで再利用する教訓専用。機能、要件、実装状況、DB/API仕様、未解決タスク、検証結果の時系列は書かない。それらはREADME.md、PLAN.md、PLAN_EDITOR.md、UPDATE.mdへ置く。
- 作業中に一時的でも「次から気を付ける」「判断方法を変える」「再発防止に使える」と認識した時点で、その教訓をこのファイルへ追記する。最終報告まで保留しない。具体的な機能名は教訓を理解する最小限の例としてだけ使い、現行仕様の代替文書にはしない。

### MEMO.md

- ユーザが気づいたことをメモする
- 今後指示する可能性があるメモなので、適宜チェックして必要であれば実装したりドキュメントを更新したりする
